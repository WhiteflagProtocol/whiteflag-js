    Class FunctionChain<D>

    Class for processing a data element by a chained sequence of functions

    Remarks

    A function chain processes a data element by passing sequentally to the functions added to chain, with the resulting (altered) data element retruned by each function passed to the next. The result of the chain is the resulting data element of the last function in the chain. All functions must accept the same parameters, with the data element processed by the chain being the first. The chain may hold zero or more functions; if the chain contains no functions, the execution of the chain returns the data element unaltered.
