    Class WfOriginator

    An organisation or person sending Whiteflag messages

    Wfversion

    v1-draft.7

    Wfreference

    2.4.1.2 Originator and Account

    Remarks

    This class represents a Whiteflag participant, e.g. a person or organisation, that sends Whiteflag messages on a blockchain. An originator may use multiple blockchain accounts.
